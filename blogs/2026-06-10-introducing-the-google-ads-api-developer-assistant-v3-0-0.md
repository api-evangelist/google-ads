We are pleased to announce the release of v3.0.0 of the Google Ads API Developer Assistant . This major release marks a significant milestone in the evolution of the Assistant, focusing on architectural modernization, improved reliability, and a more modular design. With this release, we are migrating the Assistant to the Google Antigravity agent framework and transitioning to a Skills-based architecture.
