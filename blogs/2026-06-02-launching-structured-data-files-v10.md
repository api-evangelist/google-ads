Today we’re announcing the general availability of Structured Data Files v10 . All users can now use v10 when downloading and uploading SDFs in the Display & Video 360 interface. SDF v10 includes the following changes to file formats: Support for CTV targeting in Line Item file entries and regional location list targeting for Ad Group file entries.
