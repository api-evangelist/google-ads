Starting on August 3, 2026 you will no longer be able to create new Smart Campaigns using the Google Ads API. You will still be able to update your existing Smart Campaigns, and they will continue to serve ads. In lieu of new Smart Campaigns, we recommend exploring other campaign types, such as Performance Max, an automated campaign type that serves across Google's advertising channels.
