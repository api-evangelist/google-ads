Google Marketing Platform event ingestion The Data Manager API has introduced support for sending offline conversion events to Google Marketing Platform products, including Campaign Manager 360, Search Ads 360, and Display & Video 360. The AdIdentifiers object now includes dclid , impressionId , matchId , and encryptedUserIds . Check out the Get started guide to see which fields are required for uploading conversions that occur away from your website.
